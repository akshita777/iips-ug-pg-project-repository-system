# 1. Problem Statement

## Title
IIPS UG-PG Academic Project Repository & Record Management System

## Problem
IIPS DAVV manages BCA (Sem 1-6) and MCA (Sem 7-10) programs with formal project submissions at Sem 6 (BCA Final) and Sem 10 (MCA Final). Currently, there is no centralized system for:

- Project submission with version control
- Guide allocation and management
- Evaluation tracking
- Longitudinal student records across 10 semesters

## Proposed Solution
A web-based system with role-based access for Students, Guides, Coordinators, Evaluators, and Admins to manage the full project lifecycle.

## Scope
- **In:** Submission, repository management, guide allocation, version control, evaluation
- **Out:** Plagiarism detection, online coding, payment integration

## Stakeholders
- Students (BCA Sem 1-6, MCA Sem 7-10)
- Faculty Guides
- Program Coordinators / HOD
- Internal & External Evaluators
- System Admin
